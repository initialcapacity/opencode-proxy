title: Write CSS
category: code
severity: suggestion

Write CSS. Learn selectors, the cascade, the box model, flex, and grid rather than
reaching for a CSS-in-JS library or a utility-class framework to sidestep them.
Browser CSS is powerful, well-specified, and universally supported; an abstraction
on top of it is a dependency, a debugging target, and a training cost for everyone
who joins the team.
