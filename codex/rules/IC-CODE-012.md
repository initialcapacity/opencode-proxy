---
id: IC-CODE-012
title: Spend time in naming
category: code
severity: important
source: https://kt.dev
---

Names are the primary interface between your code and the next reader. Spend the
minute it takes to pick one that says what the thing is, not what its type is or
where it happens to be used today. A good name makes a comment unnecessary; a bad
name makes every comment necessary. If you cannot name a function cleanly, it
probably does two things.
