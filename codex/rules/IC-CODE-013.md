title: Spend time in organization
category: code
severity: suggestion
source: https://kt.dev
---

Where a thing lives matters. A file with a sensible name in a sensible directory
tells the next reader where to look and where to add new behavior. Keep file
structures flat when content is small; introduce directories when the content
justifies them, not to hit some abstract "layer" shape. Revisit organization when
the current layout stops matching how the code is actually used.
