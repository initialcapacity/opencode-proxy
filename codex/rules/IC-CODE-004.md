title: Write HTML
category: code

Write HTML. Use semantic elements — `<form>`, `<button>`, `<label>`, `<nav>`,
`<main>` — rather than styling divs to look like them. Semantic HTML is accessible
by default, works without JavaScript, is indexable by search engines, and gives
assistive technology a map of the page that no amount of ARIA can fully replace.
