---
id: IC-CODE-005
title: Write SQL
category: code
severity: suggestion
source: https://kt.dev
---

Write SQL. Learn joins, aggregates, window functions, and query plans rather than
relying on an ORM or a query builder to hide the database from you. SQL is the
native language of relational databases; every layer you put between your code and
the database is a layer where performance problems hide and expressive power gets
lost.
